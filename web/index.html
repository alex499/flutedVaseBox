A fluted, stackable box for vase-mode printing, rendered here in your browser by OpenSCAD itself.

Size

Everything else — flute pitch, corner rounding, the stacking foot — is measured off the original and scales automatically; the flute count changes with size so each groove stays close to 5 mm wide, rather than stretching.

Model flutedVaseBox, a remix of Stackable Box (vase mode) by Chris (Aero)Engineering Design, CC BY‑NC‑SA 4.0. Geometry by OpenSCAD (GPL‑2.0), compiled to WebAssembly.
